Справка

⌨️ Горячие клавиши

  • Пробел / K — воспроизвести / пауза
  • J / L или ← / → — ∓10 сек
  • Shift+J/L — ∓30 сек
  • P / N — предыдущий / следующий файл
  • ↑ / ↓ — громкость, M — без звука
  • 0–9 — переход к 0%–90% файла
  • Esc — закрыть справку

📱 На телефоне (Android)

  • Меню браузера ⋮ → «Установить приложение» — появится иконка на рабочем столе и полноэкранный режим.
  • Играет в фоне при выключенном экране; перемотка и пауза доступны с экрана блокировки и из шторки уведомлений.
  • Мини-плеер внизу экрана позволяет управлять воспроизведением, пока вы выбираете другую книгу в каталоге.
  • Кнопка «назад» возвращает из плеера к книге, а со страницы книги — в каталог.
  • Позиция каждого файла сохраняется в памяти телефона.

📚 Как устроен каталог

  • Каталог загружает папки и подпапки из привязанной папки Яндекс Диска.
  • Из каждой папки автоматически подтягивается картинка обложки и текстовый файл с описанием.
  • Клик по папке или подпапке открывает страницу книги; кнопка «Слушать» переносит в плеер.
  • Прогресс прослушивания отмечается прямо на карточках в каталоге и на полке «Продолжить».

ℹ️ О работе плеера

  • Используется официальный API Яндекс Диска — перемотка по длинным файлам работает сразу, без скачивания файла целиком.
  • «Усиление» — предусилитель до 300% для тихих записей с мягким лимитером пиков.
  • Автопереход к следующему файлу срабатывает и при обрыве потока в конце длинного файла.
  • Позиция сохраняется каждые 3 секунды и при закрытии вкладки (localStorage).
