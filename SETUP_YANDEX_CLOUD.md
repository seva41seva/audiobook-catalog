# Настройка семейного доступа через Yandex Cloud Functions и `app:/` Яндекс Диска

Эта инструкция описывает, как подключить серверный шлюз (`cloud-function/`) к вашему каталогу аудиокниг (`index.html`), чтобы:

- **Родные и друзья** регистрировались по вашей **пригласительной ссылке** (только Имя + PIN из 4–6 цифр, без аккаунта Яндекса) и синхронизировали прогресс между своими устройствами;
- **Вы (администратор)** входили через свой аккаунт Яндекса и видели скрытую от обычных слушателей панель **«⚙ Админ»**: управление пригласительными ссылками, статистику прослушивания, сброс PIN, блокировку/удаление профилей, кэш каталога и резервные копии;
- **Все служебные данные** хранились изолированно в скрытой папке приложения **`app:/`** на вашем Яндекс Диске (`Приложения/<Имя вашего OAuth-приложения>`), не смешиваясь с публичной папкой аудиокниг и не раскрывая ваши токены в браузере слушателей.

> Пока `CATALOG_CONFIG.apiBaseUrl` в `index.html` остаётся пустым (`""`), сайт продолжает работать в прежнем **локальном режиме** (`localStorage`).

---

## Шаг 1. Создайте OAuth-приложение в Яндексе

1. Откройте [https://oauth.yandex.ru/](https://oauth.yandex.ru/) под тем аккаунтом Яндекса, который будет администратором.
2. Нажмите **«Создать приложение»**.
3. Заполните основные поля:
   - **Название сервиса:** например, `Аудиотека` (так же будет называться папка в `Приложения/` на вашем Яндекс Диске).
   - **Платформы:** выберите **Веб-сервисы**.
   - **Redirect URI (Callback URL):** укажите **точный URL вашего сайта без `#hash` и `?параметров`**, например:
     ```text
     https://seva41seva.github.io/audiobook-catalog/
     ```
     *(Если открываете сайт и по локальному адресу для проверки — можно добавить второй Redirect URI, например `http://localhost:8080/`.)*
4. В разделе **Доступ к данным** найдите и отметьте ровно два права:
   - `cloud_api:disk.app_folder` — **Доступ к папке приложения на Диске**
   - `login:info` — **Доступ к логину, имени и ID пользователя**
5. Сохраните приложение и скопируйте:
   - **ClientID** (`YANDEX_CLIENT_ID`)
   - **Client secret** (`YANDEX_CLIENT_SECRET`)

Узнать свой цифровой **ID** или **логин** на Яндексе можно в личном кабинете Яндекс ID (обычно логин — часть почты до `@yandex.ru`).

## Шаг 2. Разверните Yandex Cloud Function

1. Откройте консоль [Yandex Cloud](https://console.cloud.yandex.ru/) → сервис **Cloud Functions** → **Создать функцию**.
2. Введите имя функции, например `audiobook-catalog-gateway`, и нажмите **Создать**.
3. В редакторе кода версии функции:
   - **Среда выполнения:** `Node.js 18` или `Node.js 22` (`nodejs18` / `nodejs22`).
   - **Способ:** «Редактор кода» или загрузка ZIP-архива из папки `cloud-function/`.
   - Поместите в корень функции два файла из репозитория:
     - `cloud-function/index.js` → `index.js`
     - `cloud-function/package.json` → `package.json`
   - **Точка входа:** `index.handler`
4. В параметрах версии задайте:
   - **Таймаут:** `60` секунд (достаточно для полной пересборки кэша каталога)
   - **Память:** `256 МБ` (или `128 МБ` — внешние зависимости отсутствуют)
5. Добавьте **Переменные окружения**:

| Переменная | Обязательна | Описание и пример |
| --- | --- | --- |
| `YANDEX_CLIENT_ID` | Да | ClientID вашего OAuth-приложения |
| `YANDEX_CLIENT_SECRET` | Да | Client secret вашего OAuth-приложения |
| `ADMIN_YANDEX_ID` | Да | Ваш логин в Яндекс ID (без `@yandex.ru`, например `seva41seva`) или числовой UID в Яндексе (не ID в Yandex Cloud; можно несколько через запятую) |
| `SESSION_SECRET` | Да | Случайная секретная строка от 32 символов (например, вывод `openssl rand -hex 32`) |
| `CATALOG_PUBLIC_URL` | Желательно | Публичная ссылка на папку с книгами, например `https://disk.yandex.com/d/Qb_HBohs2k5iEg` |
| `ALLOWED_ORIGINS` | Желательно | Origin вашего сайта для CORS, например `https://seva41seva.github.io` (или `*`) |
| `YANDEX_REFRESH_TOKEN` | После шага 4 | Токен доступа к `app:/` — вы получите его автоматически на Шаге 4 |

6. Нажмите **Создать версию**.
7. На странице **Обзор** функции:
   - Включите переключатель **«Публичная функция»** (иначе браузер не сможет обращаться к ней без IAM-токена).
   - Скопируйте **Ссылку для вызова** вида:
     ```text
     https://functions.yandexcloud.net/d4e1234567890abcdef
     ```

## Шаг 3. Пропишите адрес функции в `index.html`

Откройте `index.html`, найдите объект `CATALOG_CONFIG` и вставьте скопированную ссылку в `apiBaseUrl`:

```js
const CATALOG_CONFIG = {
  yandexDiskUrl: "https://disk.yandex.com/d/Qb_HBohs2k5iEg",
  apiBaseUrl: "https://functions.yandexcloud.net/d4e1234567890abcdef",
  title: "Аудиотека",
  subtitle: "Каталог аудиокниг · Яндекс Диск",
  cacheTtlMs: 15 * 60 * 1000,
};
```

Сохраните изменения и отправьте коммит в GitHub (если сайт размещён на GitHub Pages).

## Шаг 4. Первый вход администратора и фиксация `YANDEX_REFRESH_TOKEN`

1. Откройте ваш сайт — появится экран входа.
2. Нажмите **«Войти как администратор (Яндекс)»** и подтвердите доступ к папке приложения.
3. После возврата на сайт откроется панель **«⚙ Админ»**, а сверху появится жёлтый баннер **«Завершите первичную настройку сервера»** со значением `YANDEX_REFRESH_TOKEN`.
4. Скопируйте этот токен, откройте вашу функцию в Yandex Cloud → **Создать новую версию** (или «Редактировать переменные окружения» в новой версии) → добавьте переменную:
   - `YANDEX_REFRESH_TOKEN` = `<скопированный токен>`
   и сохраните новую версию функции.
   > С этого момента сервер сможет самостоятельно обновлять доступ к `app:/`, даже когда вы не заходите в браузер (например, когда ваши родственники регистрируются или синхронизируют прогресс).
5. В панели администратора:
   - Нажмите **«Инициализировать папки app:/»** (создадутся `app:/users`, `app:/progress`, `app:/cache`, `app:/stats`, `app:/config.json`).
   - Нажмите **«Пересобрать кэш каталога»** — функция просканирует вашу публичную папку и сохранит индекс в `app:/cache/catalog-index.json`, после чего каталог у всех пользователей будет открываться за 1 запрос.

## Как пользоваться доступом после настройки

- **Пригласить родных и друзей:** в панели **«⚙ Админ»** скопируйте **пригласительную ссылку** (`https://.../#invite=...`) и отправьте её в мессенджер.
- **Регистрация по ссылке:** человек переходит по ссылке, вводит своё **Имя** и придумывает **PIN (4–6 цифр)**. Его данные сохраняются в `app:/users/<hash>.json`.
- **Повторный вход с любого устройства:** на экране входа достаточно ввести **Имя + PIN** (список пользователей никому не показывается). После 5 неверных попыток ввода PIN профиль автоматически блокируется на 15 минут.
- **Отзыв пригласительной ссылки:** кнопка **«Создать новую ссылку»** в админке мгновенно делает все прежние пригласительные ссылки недействительными для новых регистраций. Уже зарегистрированные пользователи при этом **продолжают входить** по своему имени и PIN.
- **Сброс PIN и блокировка:** в списке пользователей в админке можно задать человеку новый PIN (старые сессии на его устройствах сразу сбросятся), временно заблокировать профиль или полностью удалить его.
- **Резервная копия:** кнопка **«Скачать резервную копию (JSON)»** выгружает конфигурацию, профили, прогресс прослушивания всех пользователей и индекс каталога в один JSON-файл.
