# Аудиотека — каталог аудиокниг с Яндекс Диска

Веб-приложение (PWA) в тёмной теме для просмотра каталога аудиокниг из публичной папки Яндекс Диска и удобного прослушивания в браузере или на телефоне.

## Возможности

- **Каталог папок и подпапок**: автоматическая загрузка обложек, текстовых описаний (`.txt`), количества файлов и прогресса прослушивания. Подпапки по умолчанию свёрнуты.
- **Поиск и фильтры**: поиск по названию и описанию, фильтр по статусу (`Все`, `В процессе`, `Новые`, `Прослушанные`), вид «Сетка / Список», полка «Продолжить прослушивание».
- **Страница книги**: большая обложка, полное описание, список глав/подпапок и кнопка «Слушать» / «Продолжить».
- **Плеер**: перемотка `∓10` / `∓30` сек, скорость `0.5×–3×`, предусилитель «Усиление» до `300%` с лимитером, закладки, таймер сна, автопереход к следующему файлу, сохранение позиции в `localStorage`, управление с экрана блокировки (Media Session) и мини-плеер.

## Как залить на GitHub и опубликовать (GitHub Pages)

1. Создайте новый репозиторий на GitHub (например, `audiobook-catalog`).
2. Загрузите **всё содержимое этой папки** (`index.html`, `manifest.webmanifest`, `service-worker.js`, `.nojekyll`, `README.md` и папку `icons/`) в корень нового репозитория (через кнопку **Add file → Upload files** или через `git push`).
3. Откройте **Settings → Pages** в репозитории.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
5. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

## Как поменять ссылку на папку Яндекс Диска

Откройте `index.html`, найдите в начале блока `<script>` объект `CATALOG_CONFIG` и замените значение `yandexDiskUrl` на ссылку на вашу публичную папку (у папки должен быть включён «Доступ по ссылке»):

```js
const CATALOG_CONFIG = {
  yandexDiskUrl: "https://disk.yandex.com/d/Qb_HBohs2k5iEg",
  title: "Аудиотека",
  subtitle: "Каталог аудиокниг · Яндекс Диск",
  cacheTtlMs: 15 * 60 * 1000,
};
```
